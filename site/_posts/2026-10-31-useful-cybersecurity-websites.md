A curated bookmark list of security reference sites, split into General, Offensive and Defensive sections. General covers CyberChef for data transforms, HackTricks cheatsheets, RExpository regexes, and domain-squatting checkers (dnstwist, HaveIBeenSquatted). Offensive lists living-off-the-land catalogs for each platform: GTFOBins (Unix), LOLBAS (Windows), LOLDrivers (vulnerable drivers), LOOBins (macOS), LOLApps, LOFLCAB, and LOLESXi, plus HijackLibs for DLL hijacking candidates. Defensive covers MalAPI (Windows APIs mapped to malware techniques), WTFBins (legitimate software that behaves like malware), and endoflife.date for EOL tracking. It has no original research, but it is a useful bookmark list for red teamers and detection engineers.
